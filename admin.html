❌ Browser Not Supported

The File System Access API is not supported by your current browser (likely Safari or Firefox).

To use the administrative interface, please use a Chromium-based browser like:

  • Google Chrome
  • Microsoft Edge
  • Brave

⚠️ Browser Security Restriction

The File System Access API and StackEdit integration are restricted when using the file:// protocol.

Please run the local server to use the administrative tools:

python3 serve_admin.py

Then navigate to http://localhost:8000/admin.html

Administrative Interface

Select a markdown file from the sidebar to start editing. This tool allows you to modify your site's content directly from the browser.

View New Style Preview (Review Board) →

How it works:

  • Click Open Project Folder and select your src/content directory.
  • Browser will request permission to see and edit your local files.
  • Select any .md file from the sidebar.
  • Click Open StackEdit to launch the professional markdown editor.
  • Changes are saved back to your disk automatically when you close the editor or finish a session.
